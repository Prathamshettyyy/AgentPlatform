## Test result

```powershell
$env:PYTHONPATH = "."
.\.venv\Scripts\python.exe -m pytest -q
```

The suite contains the original tests plus invalid-workflow, rejection-path, converging-DAG, immutable-version, durable-restart, scheduler, agent/tool manifest validation, API extensibility, Ollama-plugin, tool-security, timeout, reuse, monitoring, approval-gating, domain-independence, CLI, agent/tool/workflow scaffolding, authentication, owner isolation, redaction, retention, concurrent-run, checkpoint-initialization, repeated-resume, legacy-persistence compatibility, external-agent connector, and direct-agent execution coverage. The hardening module passed **7 tests**. Focused direct-agent/API/CLI/connector/security tests passed **32 tests with 14 dependency warnings**. The default deterministic suite passed **82 tests with 1 skipped and 34 warnings**. With live Ollama enabled (`OLLAMA_BASE_URL=http://127.0.0.1:11434`, `OLLAMA_MODEL=llama3.2:3b`, `RUN_OLLAMA_TESTS=1`), the complete suite passed **83 tests with 34 warnings**. The skipped test is the optional Ollama test when the live flag is not enabled. A separate real-agent acceptance run also passed through `agents run` and the API using an in-memory repository.

## Warnings

The suite emits dependency warnings but no failures. Current full runs have 34 warning instances from three dependency/framework sources: Starlette's AnyIO `BlockingPortal` alias deprecation; LangGraph's pending `allowed_objects` default change; and LangGraph's internal use of Python 3.16-deprecated `asyncio.iscoroutinefunction` at two call sites. The connector's API workflow test exercises an existing LangGraph call site; no application-owned warning or new warning category was found. `aiosqlite==0.20.0` remains pinned because the installed LangGraph SQLite checkpoint API expects that connection interface. No warnings were suppressed globally.
